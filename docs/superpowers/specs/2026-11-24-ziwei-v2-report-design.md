# 紫微光年 V2.0 · 命盘报告视觉与交互设计规范

> 版本：V2.0 规范草案（2026-11-24）
> 范围：完整报告（`report_type = 'full'`）的网页呈现与 PDF 导出
> 不在范围：免费基础报告、排盘算法、支付链路、账号体系
> 说明：本文件是设计与开发规范，不构成对排盘结果或解读准确性的验证。

---

## 1. 产品定位

**紫微光年 · 东方命盘典藏**

- 用户购买的不是一份 PDF，而是一份**长期可回看的私人命盘档案**（账号级永久权益，$9.99 一次性）。
- 网页是主产品，PDF 是导出权益。
- 核心感受目标：**专属感、东方神秘感、典藏感**，而不是"算命网站的结果页"。

一句话主张：**一盘一世界，读懂命盘，也读懂自己。**

---

## 2. 现状与真实约束（开发前必须知道）

| 项目 | 现状 |
| --- | --- |
| 技术栈 | Next.js 16 App Router、Tailwind + 手写 CSS、Supabase、Railway |
| 报告页 | 单文件客户端组件 `app/report/[id]/page.tsx`（组件偏大，V2 需拆分） |
| 完整报告正文 | **模板生成**（`lib/full-report.ts`），`ai_model = 'local-template'`，当前**未调用任何 AI 模型** |
| 排盘数据 | 引擎产出 `chart_data`：十二宫、主/辅/煞/杂曜、亮度、生年四化、宫干自化、大限、长生/博士十二神 |
| 多语言 | 6 语言（zh/en/es/fr/de/ja），文案集中在 `lib/i18n.ts` |
| 权益 | `full_report` 为**账号级永久**权益，一次购买解锁该账号所有完整报告 |
| PDF | 浏览器打印（print CSS），无服务端 PDF 生成 |
| 呈现组件 | `ChartBoard`（盘面）、`.report` 章节、`.palace` 折叠卡片 |

**关键纠正**：当前报告"读起来像批量生成"，根因是**正文由模板拼装**，不是 AI 写得不好。若要实现"综合宫位 + 主星 + 辅星 + 四化 + 关系"的整体解读，必须新接入模型调用，属于新增能力，需要单独评估成本与延迟（见 §9 决策点 D1）。

## 3. 三层视觉系统

三层场景切换，避免全篇星空导致廉价感与阅读疲劳。

### L1 星空典藏（深色）

- 用于：封面、命盘总览、结尾封印页。
- 底色：`#08090C → #0B0C10` 径向渐变；星点密度低，金线细。
- 主色：香槟金 `#B8945C`、亮金 `#D9BC86`；文字 `#F5EEDF`。
- 元素：金线星轨（缓慢旋转）、十二宫环形图、专属印章、编号。
- 禁止：大面积纯黑 + 高饱和霓虹；星点闪烁频率高于 8s。

### L2 东方典籍（浅色，正文主体）

- 用于：性格、十二宫、专题、大限。
- 底色：宣纸 `#FBF8F1`，卡片 `#FFFDF7`；正文 `#1A1A1A`，次级 `#4A4034`。
- 装饰：细金线 `rgba(184,148,92,.35)`、极淡纹样（不透明度 ≤ 4%）、章节编号。
- 排版：标题宋体、正文宋体、数字与英文用衬线拉丁字体；正文行高 ≥ 2.0。
- 禁止：正文使用低于 4.5:1 对比度的灰（当前 `.ch-body p` 为 0.78 透明度，V2 提升到 ≥ 0.86）。

### L3 命盘封印（深色 + 朱砂）

- 用于：章节小结、当前阶段、结尾封印。
- 底色：`#0E0B0A` 或深褐；金色 `#B8945C`；朱砂 `#A03428`。
- 元素：朱砂印章（旋转 -6°）、编号、结论短句。
- 使用频率：全篇 ≤ 4 处，否则仪式感失效。

### 设计令牌（新增到 `globals.css`）

```

--v2-ink: #1a1a1a;
--v2-ink-2: #4a4034;

--v2-gold: #b8945c;

--v2-gold-deep: #7a5b33;

```

## 5. 关键页面规范

### 5.1 封面（01）

- 全幅 L1 深色；中央偏右 60% 宽度放环形十二宫（现有 `CoverChart` 升级：加星轨、宫位名、四化点）。
- 左上角小字：`ZI WEI INSIGHT · 紫微斗数`；主标题「命盘全解」；副题「致 {姓名}」。
- 底部三行：出生四要素 · 档案编号 `ZW-{YYYY}-{ID8}` · 生成日期。
- 金线框：内缩 24px，1px `rgba(184,148,92,.35)`；四角加 12px 短线角标。
- PDF：单独成页，深色**不**打印为白底，改为浅色版封面（见 §8）。

### 5.2 排盘资料与确认项（02，新增）

必须明确区分三类信息：

1. **已确认的排盘输入**：出生日期、地点、时区、是否已知时辰。
2. **依赖时辰的判断**：时柱、部分宫位与星曜落宫、大限起运。
3. **AI 的倾向性解释**：所有"你可能/你倾向于"的表述。

规则：

- `timeKnown = false` 时，页面顶部显示醒目标注：「未提供出生时辰，时柱相关判断以子时（00:00）排盘，仅供参考」。
- 该状态下，涉及时辰的章节加统一角标「依赖时辰」，并在文末汇总。
- 数据不确定处不得使用确定性措辞（"必然/一定会"）。

### 5.3 十二宫卡片（06 的核心）

每宫一张卡，结构固定：

```
宫名 · 地支 · 大限区间 · 命宫/身宫标记
主星：名称 + 亮度（庙旺平陷）+ 四化章
辅/吉星：名称列表（最多 6 个，超出折叠）
煞/杂曜：名称列表（弱化色）
空宫：显示「借对宫 {星名}」
解读：① 整体判断（1 句）② 星曜为何形成此组合（2–3 句）③ 对你的具体影响（2–3 句）
```

- 解读正文**禁止**"这里有 X 星——你如何如何"的并列句式，必须先给结论再解释成因。
- 每宫正文长度上限 180 字，超出进入专题（07）。
- 四化用小方章：禄（金）、权（朱）、科（青）、忌（墨）。

### 5.4 大限时间轴（08）

- 横向 12 段，当前段高亮（金色描边 + 轻微上浮）。
- 每段显示：年龄段、宫位、主题词（3–6 字）。
- 下方展开当前段正文 + 「下一步」提示（仅提示，不做预测断言）。

### 5.5 封印与结语（12）

- L3 深色整页；中央朱砂印章 + 「命由天定，运由己造」。
- 档案编号、生成日期、品牌落款。
- 一句只属于该用户的收尾话（新增字段，可模板 + 变量生成）。

## 6. 交互规范（网页）

| 交互 | 行为 |
| --- | --- |
| 盘面点击宫位 | 平滑滚动到对应宫位卡，并短暂高亮 1.2s |
| 宫位卡点击星曜 | 弹出星曜释义（200 字内），不跳页 |
| 目录 | 固定侧栏（桌面）/ 顶部抽屉（移动端），当前章节高亮 |
| 当前大限 | 自动高亮，进入页面时若存在 #current 则高亮 |
| 阅读进度 | 顶部 2px 金色进度线（已存在 `.progress`，复用到报告页） |
| 移动端 | 盘面可横向缩放；卡片单列；正文字号 ≥ 16px |

动效约束：入场淡入 ≤ 600ms；星轨旋转周期 ≥ 300s；尊重 `prefers-reduced-motion`。

## 7. 技术方案

### 7.1 组件拆分（现状单文件 → 拆分）

```
app/report/[id]/page.tsx        仅做数据获取与编排
components/report/Cover.tsx     封面（L1）
components/report/MetaPanel.tsx 排盘资料与确认项
components/report/ChartStage.tsx 盘面舞台（复用/升级 ChartBoard）
components/report/Chapter.tsx   章节容器（编号 + 标题 + 导语）
components/report/PalaceCard.tsx 宫位卡
components/report/DaXianTimeline.tsx
components/report/Colophon.tsx
```

### 7.2 内容模型扩展

`full` 报告 `content` 新增字段（向后兼容，缺省时隐藏对应章节）：

```jsonc
{
  "oneLiner": "string",            // 04 一句话认识自己
  "topics": {
    "career": "string",            // 07 事业
    "wealth": "string",
    "love": "string"
  },
  "strengths": "string",           // 11 优势
  "challenges": "string",          // 11 挑战
  "exploration": "string",         // 11 自我探索
  "timeDisclosure": {              // 02 时辰披露
    "timeKnown": true,
    "dependsOnTime": ["时柱", "部分宫位", "大限起运"]
  }
}
```

- 旧报告缺失新字段时，页面自动隐藏 04/07/11，不做迁移、不重算。
- 新报告在生成时写入；是否由 AI 生成见 §9 D1。

### 7.3 PDF 导出

- 阶段一（V2.0-a）：继续用 print CSS，但需补齐：封面浅色版、三层视觉的打印降级、章节强制分页、卡片防断页、目录页码位。
- 阶段二（可选）：服务端渲染 PDF（Puppeteer/Playwright），输出带页码与页眉的固定版式；用户下载的是成品而非浏览器打印结果。

## 8. PDF 打印降级规则

| 网页元素 | PDF 处理 |
| --- | --- |
| L1 深色封面 | 改浅色宣纸版：金框 + 深墨字 + 隐藏星空，避免整页耗墨 |
| L3 封印页 | 保留深色（仅 1–2 页），其余页浅色 |
| 星轨/星光动画 | 全部隐藏 |
| 宫位卡 | 白底细金框，`break-inside: avoid` |
| 目录 | 独立页，深色字 + 金色编号 |
| 交互控件（按钮/导航/浮动目录） | 隐藏 |
| 正文对比度 | 提升到 ≥ 4.5:1 |

## 10. 分阶段交付

### V2.0-a 视觉与结构（不改内容生成）

1. 设计令牌 + 三层场景样式。
2. 拆分报告页组件。
3. 封面升级（致语、金框、编号、环形盘）。
4. 目录改为章节导航；十二宫卡片化；大限时间轴。
5. 封印结语页。
6. PDF：浅色封面、目录页、封印页、卡片防断页。
7. 02 排盘资料与确认项（纯前端，使用已有 `timeKnown` 数据）。

验收：网页与 PDF 各页无空白/断卡；封面与目录文字对比度 ≥ 4.5:1；盘面在移动端可用。

### V2.0-b 内容升级（新增字段 + AI）

1. `content` 扩展字段与后端写入。
2. 十二宫解读结构改造（结论优先）。
3. 04 / 07 / 11 三章生成。
4. 样张评估（20 份），确认后再全量。

验收：同一份盘重复生成风格一致；不含确定性断言；时辰不明时正确标注。

### V2.0-c 交互增强

1. 宫位点击跳转与高亮。
2. 星曜释义浮层。
3. 桌面侧栏目录 / 移动端抽屉。
4. 阅读进度线。

## 11. 验收标准（总）

- [ ] 免费用户仍只看基础盘（骨架 + 主星），不回归。
- [ ] 完整报告所有新增章节在旧数据下自动隐藏，不报错。
- [ ] 时辰未知时，02 章与相关章节有明确标注。
- [ ] 网页 6 语言无硬编码中文。
- [ ] PDF：封面/目录/封印各占一页；无空白页；无跨页断卡；对比度达标。
- [ ] 移动端 375px 宽度下盘面不溢出、正文可读。
- [ ] 不修改排盘引擎、支付链路、账号体系。
