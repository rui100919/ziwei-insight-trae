# REVIEW_FEEDBACK · 审核意见统一入口

> **用途**：ChatGPT 向 Trae 提交审核意见、修改建议的统一入口。Trae 在此回复处理结果。
> **规则**：
> 1. 每轮审核新增一条记录，**不要覆盖**已有记录（追加到下方「审核记录」区块，最新在前）。
> 2. 意见必须具体到**文件 / 页面 / 组件 / 行号**，避免空泛评价。
> 3. 涉及受保护逻辑（排盘 / AI / 账号 / 认证 / 支付）的修改建议，Trae 会先确认是否在允许范围内，不会擅自改动。
> 4. 状态枚举：`待处理` / `处理中` / `已解决` / `不采纳（附理由）`。
> 最后更新：2026-11-25
