## 一、品牌与视觉方向

- **品牌定位**：Mystical Cosmic Luxury（神秘宇宙奢华）。
- **目标用户**：欧美年轻 Astrology / Spirituality / Self-discovery 人群，同时支持中文。
- **情绪基调**：克制、准确、被理解；不堆砌动效、不滥用渐变。
- **核心手法**：外层深空（品牌 / 导航 / 封面 / 支付）→ 阅读层柔象牙（报告正文），在「开始阅读」那一刻切换底色，形成情绪节奏。

## 二、设计系统（一套，双端共用）

### 色彩 —— 深空五色（已拍板）
| Token | Hex |
|---|---|
| midnight navy | `#05081A` |
| cosmic indigo | `#121A3C` |
| nebula purple | `#2E2456` |
| champagne gold | `#C9A96A` |
| soft ivory | `#F5EFE3` |

语义别名：深色面 `--text/--muted/--faint/--line/--line-gold`；阅读面 `--paper/--ink-text/--ink-muted/--ink-line`。

### 字体
- **展示体（拉丁 + 数字）**：Cormorant Garamond（300/400/500/600 + 斜体）—— 用于标题、眉标、编号、价格。
- **正文 + CJK**：Noto Serif SC（300/400/500/600）—— 用于所有正文与中文/日文。
- 通过 `next/font/google` 加载，`display: swap`。两者均为 OFL 许可，商用无风险。
- 品牌 UI 不使用无衬线体（仅城市选择器等输入框因可读性用系统 sans）。

### 间距 / 圆角 / 动效
- 间距：4pt 栅格 `4/8/12/16/20/24/32/40/56/72/96/128`。
- 圆角：`2 / 8 / 14 / 22 / 999`（卡片 14、移动大面板 22、标签 pill）。
- 动效：`180ms` 反馈 / `320ms` 位移 / `600ms` 入场；统一 `prefers-reduced-motion` 降级为静态。

## 三、响应式策略

- **移动优先**：全部断点改用 `min-width`（现状是 10/12 为 `max-width`，必须翻转）。
- 断点：`sm 600` / `md 900` / `lg 1024` / `xl 1440`。默认样式面向最小屏，向上增强。
- 回归宽度：**360 / 375 / 390 / 430 / 768 / 1024 / 1440** 七档全部通过，无横向溢出。
- 桌面内容最大宽度 `1320px`；正文阅读行长 `620px`。

## 四、两套布局（同一套设计系统）

### 移动端（默认，< 900）
- **底部四栏导航**（新增 `MobileTabBar`）：`命盘 / 报告 / 探索 / 我的`，44px 触控高度；认证/法务/支付成功页不显示。
- 顶部只留品牌 + 语言 + 账户；不做全局汉堡，二级导航在底部栏与页内锚点。
- 单列叙事；命盘在手机上字号下限 12px。
- 十二宫 = 手风琴卡片（`PalaceCards`），顶部命宫/身宫快捷跳转。
- 大限 = 纵向时间轴（`DaXianTimeline`），当前大限高亮并自动滚入视野。
- 报告：深空封面 → 柔象牙正文，17px / 1.95 行高，金色章节号，结尾回扣。
- 支付：一屏一件事（价格 → 包含内容 → 支付方式 → 安心说明）。

### 桌面端（≥ 900）
- 顶部导航（`DesktopNav`），滚动后毛玻璃。
- 命盘默认**可交互环盘**（`PalaceWheel`，SVG 12 扇区点击 → 右侧详情），可切方盘。
- 报告三栏：左侧固定目录 + 中间 620px 正文 + 右侧当前章节上下文。
- 十二宫：环盘为主，方盘为「对照视图」。
- 大限：横向时间轴，点节点切换详情面板。
