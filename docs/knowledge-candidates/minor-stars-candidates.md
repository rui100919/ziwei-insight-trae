## 1. 口径与授权

### 1.1 写作口径

- 只写性格与行事倾向，不判吉凶、不预测具体事件、不做健康或寿命断言。
- 传统断语里的「孤克」「淫」「官灾」「夭寿」等一律转写为中性倾向，例如「容易为别人耗神」「对暗处的事敏感」。
- 每条先给中文单句（可直接进 `AUX`），英文草稿仅供审阅；es / fr / de / ja 批准后再补，避免 30×6 的审阅负担。

### 1.2 来源原则

- 古籍底本为公版《紫微斗数全书》（明嘉靖庚戌罗洪先序，1550）。
- 开源项目只用于核对「星名、起法、盘面层级」，不摘抄其解释性文字。
- 明确不采用：现代出版物释义、付费课程讲义、带 NC（非商用）限制的引文数据集。

## 4. 需要你拍板的 5 件事

1. **封诰起法冲突**：古籍卷二作「寅宫起子顺数」，iztro 文档作「逆到时」。引擎已按其中一版排盘，词条释义不受影响，但知识库要记哪一版？
2. **年解要不要写本命性格**：它在传统里是流年神煞，iztro 却排了「生年年解」。建议词条保留一句，但注明「流年意味更重」。
3. **天德 / 月德 的双层身份**：它们既是杂曜，也出现在岁前十二神／流年体系。建议只给「杂曜层」写词条，十二神继续走 `shier-shen.ts`，两边不共用。
4. **空亡组四颗怎么处理**：截空、副截、旬空、副旬。建议各自保留一行（盘面按名查词条），但文案必须互相区分，避免四句看起来一样。
5. **易混星对是否在词条里点名**：天空 vs 地空、蜚廉 vs 飞廉、天福 vs 天府。建议至少「天空」和「蜚廉」点名，其余靠文案错开。

## 7. 第二批（2026-11-24 已完成）

### 7.1 口径

- 十二神是岁运 / 阶段标记，不是先天性格；统一写成「偏向…的标记」「像…的阶段」。
- 不判吉凶、不预测事件、不做健康与寿命断言；传统「病、死、墓、绝」只作阶段名，释义已去事件化。
- 星曜词条（`STARS` / `AUX`）与神名白话（`SHIER_SHEN_PLAIN`）互不复用；同名不同层（天德、华盖、咸池、大耗）各按所在层解释。
- 起法沿用引擎现状：长生取 iztro `changsheng12`，博士取 `boshi12`，将前 / 岁前沿用 `shier-shen.ts` 的公式与金标准盘核对结果。
- 四组共 48 个神位，小耗、官符、病符三组重名，合并为 1 条，故 `SHIER_SHEN_PLAIN` 实收 45 条。

出处简写：**S2** =《紫微斗数全书》卷二「安星诀」（公版）；**S4** = iztro 源码 `decorativeStar.js`（MIT，仅核起法）；**金标准** = 项目内金标准盘逐宫核对。
